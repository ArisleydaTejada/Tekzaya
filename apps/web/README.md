# @tekzaya/web

Interfaz de Tekzaya: React 19, Vite, Tailwind 4, TanStack Query y Recharts.

Se arranca desde la raíz del repositorio con `npm run dev`, junto con la API. La
instalación, las cuentas de demostración y los comandos están en el
[README principal](../../README.md); el sistema de diseño, en
[`docs/DESIGN.md`](../../docs/DESIGN.md).
